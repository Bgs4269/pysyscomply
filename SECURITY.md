# Security Policy

While in the 0.x phase, the code is considered fast iterative, and only the last version is supported.

Once reaching 1.x+, normal support follows.

## Supported Versions

| Version  | Supported          |
| -------- | ------------------ |
| 0.4.1    | :white_check_mark: |
| <= 0.4.0 | :x:                |

## Reporting a Vulnerability

Please open an issue, or if you have a patch, open a PR.

Requests are reviewed with priority:
Security issue > DoS type issue > functional issue > logging issue > new feature.
